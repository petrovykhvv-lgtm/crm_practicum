# План реализации CRM-lite

Порядок: сначала `database`, затем `backend`, затем `frontend`. Каждый шаг завершается рабочим состоянием и коммитом.

- [x] Дизайн-система
- [x] Технические границы
- [x] `README.md`: легенда, сущности, статусы, стадии, быстрые действия, метрики
- [x] `Plan.md`

## Фаза 1. Инициализация
- [x] Next.js (App Router) + TypeScript, ESLint.

## Фаза 2. Database
Схема `schema.prisma`, начальная миграция `init` и первый `seed` уже созданы в фазе 1 для воспроизводимого запуска. В этой фазе они дорабатываются.
- `schema.prisma`: `Lead`, `Account`, `Contact`, `Opportunity`, `Stage`, `Activity` и enum-ы (`LeadSource`, `LeadStatus`, `OpportunityStatus`, `ActivityType`).
- Правила удаления: компания с контактами или сделками не удаляется, лид с конвертацией не удаляется, при удалении сделки удаляются её активности.
- Индексы по полям поиска и фильтров (`status`, `source`, `stageId`, `dueDate`).
- Миграция и воспроизводимое применение схемы (`prisma migrate`).
- `seed`: стадии, компании, контакты, лиды во всех статусах и источниках, сделки на всех стадиях, задачи в том числе просроченные.
- `reset`: сброс БД и повторный seed.

## Фаза 3. Backend
- Prisma-клиент (singleton) в `src/lib/db.ts`.
- Zod-схемы для входных данных, общие для клиента и сервера.
- Route Handlers или Server Actions:
  - [x] CRUD: лиды, компании, контакты, сделки (Server Actions + Zod);
  - активности: создать заметку и задачу, отметить `done`;
  - список с поиском, фильтрами и пагинацией;
  - `convertLead` (транзакция);
  - `changeStage` с правилами `won` и `lost`;
  - `dashboard`: агрегирующие запросы по метрикам из `README.md`.
- Единый формат ошибок валидации.

## Фаза 4. Frontend
- [x] Каркас: боковая навигация, стеклянные карточки, общие компоненты (кнопки, поля, бейджи, таблицы).
- [x] Списки с поиском и фильтрами: лиды (источник, статус), сделки (стадия, статус), компании, контакты; глобальный поиск.
- [x] Формы создания и редактирования с валидацией.
- [x] Карточки сущностей со связями и лентой активностей (только чтение).
