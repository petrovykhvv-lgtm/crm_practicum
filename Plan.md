# План и история реализации CRM-lite

Порядок слоёв: `database` → `backend` → `frontend`. Каждая фаза закрывалась рабочим состоянием и коммитом.

## Фазы

- [x] **0. Рамки проекта:** легенда, MVP, статусы, стадии, метрики ([docs/product.md](docs/product.md)), дизайн-система, технические границы.
- [x] **1. Инициализация:** Next.js, строгие версии пакетов, Docker/PostgreSQL, `.env.example`, токены дизайна.
- [x] **2. Database:** схема Prisma, миграции, seed/reset с контрольными данными.
- [x] **3. Backend:** Server Actions + Zod для CRUD, конвертации лида, смены стадий с правилами `won`/`lost`, активностей, агрегаций дашборда.
- [x] **4. Frontend:** списки, карточки, формы, поиск и фильтры, воронка с перетаскиванием, быстрые действия, дашборд с Chart.js.
- [x] **5. UX-доработки по ревью:** контраст, мобильная вёрстка, заголовки страниц, страница «Задачи», правка активностей, окно подтверждения, сводка ошибок форм, фиксированная шапка, логотип.
- [x] **6. Самооценка и улучшения (пункты 1–17):**
  - надёжность: автотесты (Vitest, 120+ тестов на отдельной БД), CI, единый часовой пояс `APP_TIMEZONE`, безопасные сообщения об ошибках, целостность активностей на уровне БД;
  - продукт: ответственные менеджеры, поиск дублей, прогноз выручки, справочник причин отказа, импорт и экспорт CSV, журнал изменений;
  - UX: компактные карточки воронки и «Отменить», сортировка, пагинация и кликабельные строки, «+ Создать», фиксированная шапка на телефоне, доступность (таблицы данных под графиками);
  - порядок: README с быстрым стартом, `docs/`, удалены автосгенерированные `AGENTS.md` и `CLAUDE.md`.
- [x] **7. Приёмка:** сценарий `запуск → seed → интерфейс → лид → convert lead → сделка → активность → воронка → dashboard` пройден вручную в браузере на отдельной чистой базе и автоматически (`scenario.test.ts`); найденные ошибки исправлены и перепроверены (см. ниже).

## Ошибки, найденные при приёмке и исправленные

| Ошибка | Как нашли | Исправление |
|---|---|---|
| Экспорт CSV портил телефоны вида `+7 900…` (защита от формул добавляла `'`), такой файл не импортировался обратно | тест шаблона импорта | правило экранирования пропускает числа и телефоны, тесты на формулы и телефоны |
| Запрос динамики падал после перехода на часовой пояс (разные параметры в `SELECT` и `GROUP BY`) | проверка страницы после рефакторинга | группировка по номерам колонок |
| Шапка не вмещала логотип, меню и инструменты на 1366 px | просмотр в браузере | компактнее отступы, переход на двухстрочную шапку до 1240 px |
| Форма после ошибки сбрасывала выбор в списках (React сбрасывает `<form action>`) | ручная проверка | отправка через `onSubmit` |
