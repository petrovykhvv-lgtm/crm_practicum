# Технические границы CRM-lite

- Сущности `Lead`, `Account`, `Contact`, `Opportunity`, `Stage`, `Activity`.
- Обязательный источник лида (`source`): `site`, `email`, `phone`, `referral`, `manual`.
- CRUD-операции для лидов, компаний, контактов и сделок.
- Списки и карточки сущностей.
- Связи между компаниями, контактами, сделками и активностями.
- Поиск и фильтры.
- Упрощённый процесс конвертации лида (`convert lead`).
- Воронка сделок по стадиям.
- Правила перехода сделки в статусы `won` (выиграна) и `lost` (проиграна).
- Активности (`Activity`) в формате заметок (`note`) и задач (`task`).
- Задача со сроком выполнения (`dueDate`) и признаком завершённости (`done`).
- Быстрые действия: создать сделку, сменить стадию, добавить `note`, добавить `task`, выполнить `convert lead`.
- Отдельный экран дашборда.
- Наличие `.env.example`, локальной СУБД PostgreSQL, схемы Prisma (`schema.prisma`), воспроизводимого способа применения схемы, сценариев сидирования/сброса данных (`seed`/`reset`) и файла `README.md`.
